# TestCompleter

Автоматический бот для решения тестов в LMS с использованием Google Gemini API и Puppeteer.

## Установка

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Скопируйте файл `.env.example` в `.env` и добавьте ваш ключ от Google Gemini API:
   ```env
   GEMINI_API_KEY=ваш_ключ
   ```

## Использование

Запустите бота:
```bash
node auto_test_bot.js
```

1. Бот откроет окно браузера Chrome.
2. Авторизуйтесь на сайте и перейдите к тесту.
3. Как только загрузится страница с вопросами, бот автоматически начнет считывать их, отправлять в Gemini и кликать по правильным ответам.
4. После завершения теста вы увидите страницу с результатами попытки.
