# TestCompleter 🤖🎓

Автоматический бот для прохождения тестов в системах дистанционного обучения (LMS, например Moodle), использующий возможности искусственного интеллекта **Google Gemini API** и браузерную автоматизацию **Puppeteer**.

## 🌟 Как это работает (Алгоритм 3 Фаз)

Бот работает максимально незаметно и эффективно благодаря продвинутому 3-фазному алгоритму:

1. **Сборщик (ФАЗА 1):** Бот принудительно отматывает тест на первую страницу, после чего прокликивает кнопку "Далее" до самого конца, незаметно сканируя и запоминая все вопросы и варианты ответов.
2. **Нейросеть (ФАЗА 2):** Собранные вопросы разбиваются на пакеты (до 30 штук) и отправляются в Gemini API. Встроенная система *каскадных резервных моделей* гарантирует, что даже если сервера Google перегружены, бот автоматически переключится на свободную модель (начиная от 3.5-flash и заканчивая 2.5-flash-lite) и получит 100% ответов.
3. **Прокликиватель (ФАЗА 3):** Скрипт возвращается на первую страницу и на огромной скорости проставляет правильные ответы, листая тест до страницы с результатами.

## 🛠 Установка

### 1. Системные требования
- Установленный **Node.js** (версия 18+).
- Установленный браузер **Google Chrome**.

### 2. Загрузка и установка зависимостей
Склонируйте этот репозиторий и установите необходимые модули:
```bash
git clone https://github.com/PavelT2000/TestCompleter.git
cd TestCompleter
npm install
```

## ⚙️ Настройка

Для работы бота требуется бесплатный API-ключ от нейросети Google Gemini.

### Получение API ключа:
1. Перейдите на сайт **[Google AI Studio](https://aistudio.google.com/app/apikey)** (потребуется VPN, если сервис недоступен в вашей стране).
2. Авторизуйтесь под своим Google-аккаунтом.
3. Нажмите кнопку **Create API key**.
4. Скопируйте сгенерированный ключ.

### Настройка `.env`
В папке с ботом скопируйте файл `.env.example` и переименуйте его в `.env`. Откройте его и вставьте ваш ключ:
```env
GEMINI_API_KEY=ВАШ_СКОПИРОВАННЫЙ_КЛЮЧ_ЗДЕСЬ
CHROME_PATH=C:\Program Files\Google\Chrome\Application\chrome.exe
PROFILE_PATH=C:\Users\user\chrome-dev-profile
START_URL=https://lms.bsuir.by/login/index.php
```
*(Если ваш Chrome установлен в другом месте, обновите `CHROME_PATH`)*.

## 🚀 Использование

Вы можете запускать скрипт двумя способами: подключившись к уже открытому окну или запустив новое. Скрипт умный и сам определяет, как лучше поступить.

### Пошаговый запуск:
1. Откройте терминал в папке проекта (`TestsWorker`).
2. Запустите бота командой:
   ```bash
   node auto_test_bot.js
   ```
3. **Авторизация:**
   - Если бот найдет открытое окно Chrome в режиме отладки, он бесшовно подключится к нему.
   - Иначе — бот сам откроет новое окно Chrome. В этом окне вам нужно **вручную залогиниться** в вашу LMS.
4. **Перехват теста:**
   - Просто откройте нужный тест и нажмите кнопку «Начать попытку».
   - Неважно, откроется тест в этой же вкладке или выскочит в новом поп-ап окне — скрипт постоянно сканирует все вкладки. Как только он увидит вопросы, в консоли появится надпись: `✅ Тест обнаружен! Начинаю автоматическое прохождение`.
5. **Завершение:** 
   - Ничего не трогайте, пока бот перелистывает страницы. 
   - По завершении тест выйдет на страницу сводки ("Ответ сохранен"). Вам останется только нажать финальную кнопку **Отправить всё и завершить тест**.

## 📝 Дебаг и решение проблем

Все действия и возможные ошибки бота не только выводятся в консоль, но и автоматически записываются в файл **`bot_debug.log`** в папке проекта.

- **Бот застрял на `⏳ Ожидание ручной авторизации...`**: Убедитесь, что вы открыли страницу с тестом. Страница должна содержать в URL `attempt.php` или `quiz`.
- **В консоли пишутся ошибки `🔀 Модель перегружена / Лимит исчерпан...`**: Это абсолютно нормально! Бот просто наткнулся на занятый сервер Google и автоматически переключается на следующую резервную модель. Тест будет решен в любом случае.
- **Ошибка `browser is already running`**: У вас уже открыт Chrome с профилем для разработки, но без активированного порта отладки. Просто закройте это окно Chrome вручную и запустите скрипт заново.
